# 평가 데이터 v2 제작 가이드

평가 데이터는 **학습 데이터와 독립**이어야 한다. 작업 중 `train.jsonl`, `dev.jsonl`, `rule_bank.json`, `train_raw/` 는 열지 않는다.

## 공통 규칙

- 직원이 ChatGPT·Claude 같은 AI에 실제로 입력할 법한 한국어 요청문. 15~100자 위주, 가끔 2~3문장
- 말투를 섞는다: 반말 지시, 존댓말, 메모·메일 붙여넣기, 목록 조각, 영어 섞임, 오타·띄어쓰기 실수 약간
- 회사·인물·수치·주소는 모두 **지어낸 것**. 실존 회사·실존 인물·실제 주소 금지
- 정답 구간 표시 기준은 `GUIDE.md` 3절과 같다:
  - 기밀 사실을 담은 최소 구절. 요청 부분("~써줘")은 넣지 않는다
  - 조사는 구간 밖, 원문에 글자 그대로
- **애매한 문장은 넣지 않는다.** 사람마다 판단이 갈릴 문장은 평가셋에 쓸모가 없다
- 출력: 한 줄에 하나씩 `{"text": "...", "spans": [["구간", "ID"], ...]}` (음성 문장은 `"spans": []`)
- 다 쓰면 `python3 data/check_eval.py data/eval_raw/<파일>.jsonl` 로 검사하고 오류를 0으로 만든다

## 고정 라벨 (개인정보, `fixed_labels.json`)

| ID | 구간 기준 |
|---|---|
| P-NAME | 이름만. `김지훈 책임` → `김지훈`, `지훈 님` → `지훈`, `Daniel Park` 그대로. 공인 이름도 표시 |
| P-ADDR | 주소 구절 전체. 예: `서울시 마포구 월드컵북로 4길 17, 3층`. 건물 동·호수만 있어도 표시 (`B동 1203호`) |
| P-SENS | 특정 개인의 민감한 사실을 담은 절. 예: `우울증 치료로 휴직 중`, `작년에 음주운전으로 벌금형` |

- 한 구간이 기밀 규칙과 고정 라벨 둘 다에 해당하면 **같은 구간을 두 번** 적는다
  - 예: `[["경고 징계", "R07"], ["경고 징계", "P-SENS"]]`
- 기밀 문장 안에 사람 이름이 나오면 P-NAME 도 반드시 표시한다

### 개인정보 함정 (음성) 예
- 이름처럼 생긴 회사·제품·브랜드: `하늘소프트`, `민준카페`
- 주소가 아닌 지명: `부산 출장`, `강남역 근처 맛집`, `판교 사옥`
- 일반 단어로 쓰인 이름 후보: `한결같이`, `이슬비`, `하늘이 맑다`
- 특정 개인이 아닌 건강·종교 이야기: `우울증 초기 증상 알려줘`, `불교와 기독교 차이`
- 소설·영화 속 인물에 관한 질문은 **넣지 않는다** (애매함)

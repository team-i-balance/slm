# 학습 데이터 제작 가이드

목표: 모델이 **규칙 설명을 읽고, 문장에서 그 규칙에 해당하는 구간을 찾는 능력**을 배우게 한다.
특정 회사 규칙을 외우게 하는 게 아니므로, 업종·규칙이 다양할수록 좋다.

## 1. 규칙 만들기

업종마다 기밀 규칙 20개. 형식:
```json
{"id": "FIN-07", "industry": "금융", "grade": "C", "action": "삭제",
 "label": "미공개 대출 심사 기준", "description": "외부에 공개하지 않은 대출 승인 점수 기준과 한도 산정 공식"}
```
- `label`: 15자 이내 명사구. `description`: "무엇을 기밀로 보는지" 한 문장, 40자 이내
- `grade`: S(민감, 변환 후 전송) 또는 C(기밀, 외부 차단). `action`: 대체 / 일반화 / 삭제 / 태그
- 업종 고유의 것 위주로 (예: 제약 → 임상 중간 결과, 게임 → 미공개 확률표, 건설 → 낙찰 예정가)
- 규칙의 절반 정도는 **용어형**(코드명, 비공개 거래처명, 내부 시스템명 등 고유명사가 핵심)도 섞는다
- ⚠️ **아래 개념은 절대 규칙으로 만들지 말고 문장에도 기밀로 표시하지 않는다** (평가 전용 규칙과 겹침):
  이사회 안건·표결, 제품 결함·리콜·불량률, 고객 해지·이탈 예정, 임원 출장·일정·동선,
  가격 인상 계획, 미발표 연구·실험 결과·성능 수치, NDA/비밀유지로 받은 파트너 기술 사양, 서비스 장애 원인 분석·포스트모템

## 2. 문장 만들기

직원이 ChatGPT·Claude 같은 AI에 실제로 입력할 법한 한국어 요청문. 길이 15~80자 위주, 가끔 2~3문장.
말투 다양하게 (반말 지시, 존댓말, 메모 붙여넣기, 메일 일부, 표/목록 조각, 영어 섞임).

규칙마다:
- **양성 8개**: 그 규칙의 기밀이 들어간 문장. 고유명사·숫자·날짜는 매번 새로 지어낸다 (실존 회사·인물 금지, 가상의 이름 사용)
- **음성(함정) 4개**: 같은 주제이지만 기밀이 아닌 문장
  - 일반론 질문 ("대출 심사는 보통 어떤 기준으로 해?")
  - 이미 공개된 정보 ("작년에 공시한 …", "출시된 …", "보도자료에 나온 …")
  - 코드명과 같은 단어가 일반 의미로 쓰인 문장 (코드명이 '오로라'면 "오로라 여행 코스")
  - 템플릿·양식 요청
- 업종마다 추가로 **복합 문장 10개**: 한 문장에 서로 다른 규칙 2~3개의 기밀이 같이 들어간 것

## 3. 정답 구간 표시 규칙 (가장 중요)

- 구간 = **기밀 사실을 담은 최소 구절**. 요청 부분("~써줘", "~정리해줘")은 넣지 않는다
- 숫자는 무엇의 숫자인지 알 수 있게 단위·지표와 함께: `영업이익 87억`, `대당 18만원에서 15% 할인`
- 고유명사는 이름만: `블루웨일`, `성진전자` (뒤 조사 제외)
- 의미형은 핵심 절: `일본 진출은 보류하고 동남아 먼저 가기로 결정`
- 구간 문자열은 **원문에 글자 그대로** 있어야 한다 (띄어쓰기·문장부호까지). 조사는 구간 밖으로
- 한 문장에 같은 규칙 구간이 여러 개면 각각 따로 표시

예:
```json
{"text": "3분기 잠정 매출이 1,240억이고 영업이익 87억이야. IR 문구 다듬어줘", "spans": [["1,240억", "R03"], ["영업이익 87억", "R03"]]}
{"text": "IR 자료 슬라이드 구성은 보통 어떻게 해?", "spans": [], "near": ["R03"]}
```

## 4. 출력 형식

- `data/train_raw/<이름>.rules.json` — `{"rules": [ ... ]}`
- `data/train_raw/<이름>.samples.jsonl` — 한 줄에 하나:
  `{"text": "...", "spans": [["구간 문자열", "규칙ID"], ...], "near": ["규칙ID"]}`
  - `near`: 음성 문장이 어느 규칙과 비슷한 주제인지 (학습 때 헷갈림 유발용 라벨로 쓴다). 양성 문장은 생략 가능
- JSON 한 줄이 깨지지 않게 큰따옴표 이스케이프 주의
- 다 쓴 뒤 `python3 data/check_raw.py data/train_raw/<이름>.samples.jsonl` 로 검사하고 오류를 고친다
